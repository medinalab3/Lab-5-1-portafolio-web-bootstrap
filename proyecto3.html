HTML

HTML semántico: por qué importa

Usar las etiquetas correctas mejora la accesibilidad, el SEO y hace que el código sea más fácil de leer y mantener.

Un <div> no dice nada sobre su contenido. En cambio, <header>, <nav>, <main>, <article>, <section> y <footer> le indican al navegador, a los lectores de pantalla y a los buscadores qué papel cumple cada parte de la página.

Una buena regla: si el contenido tiene sentido por sí solo (una noticia, una publicación), usa <article>; si es un grupo temático dentro de algo mayor, usa <section>. Y respeta la jerarquía de títulos: un solo <h1> por página y sin saltar niveles.

CSS

Flexbox vs. Grid: cuándo usar cada uno

Los dos sistemas de maquetación de CSS resuelven problemas distintos. Aprende a elegir el adecuado.

Flexbox trabaja en una sola dimensión: una fila o una columna. Es ideal para barras de navegación, alinear botones o centrar un elemento con justify-content y align-items.

Grid trabaja en dos dimensiones a la vez: filas y columnas. Es la mejor opción para la estructura general de una página o para galerías, por ejemplo con grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)).

En la práctica se combinan: Grid para el esqueleto y Flexbox dentro de cada bloque.

JavaScript

JavaScript moderno en 5 minutos

let, const, funciones flecha, plantillas de texto y módulos: lo esencial de ES6+.

Olvida var: usa const para valores que no se reasignan y let para los que sí. Ambos respetan el ámbito de bloque.

Las funciones flecha acortan el código: const doble = n => n * 2;. Las plantillas de texto permiten insertar variables: `Hola, ${nombre}`.

Con los módulos (import / export) puedes dividir tu aplicación en archivos pequeños y reutilizables, cargándolos con <script type="module">.

Frameworks

Diseño responsivo con Bootstrap 5

Cómo el sistema de grid de 12 columnas y los breakpoints te ayudan a adaptar una página a cualquier pantalla.

Bootstrap divide cada fila en 12 columnas. Con clases como col-12 col-md-6 col-lg-4 una tarjeta ocupa todo el ancho en el celular, la mitad en tablet y un tercio en computadora.

Los breakpoints (sm, md, lg, xl, xxl) siguen el enfoque mobile first: primero diseñas para pantallas pequeñas y luego amplías.

Este mismo portafolio usa ese grid en todas sus páginas.

Frameworks

Primeros pasos con React

Componentes, props y estado: los tres conceptos que necesitas para empezar con la librería más usada del front-end.

En React la interfaz se divide en componentes: funciones que devuelven JSX, una sintaxis parecida a HTML dentro de JavaScript.

Las props son los datos que un componente recibe de su padre, y el estado (useState) guarda los datos que cambian con la interacción del usuario. Cuando el estado cambia, React vuelve a dibujar solo lo necesario.

Para empezar un proyecto hoy, lo más sencillo es usar Vite: npm create vite@latest.

Accesibilidad

5 reglas básicas de accesibilidad web

Pequeños cambios que hacen que tu sitio funcione para todas las personas, incluidas las que usan lector de pantalla o teclado.

  1. Toda imagen informativa necesita un alt descriptivo.
  2. El texto debe tener suficiente contraste con el fondo (mínimo 4.5:1 según WCAG).
  3. Todo debe poder usarse con el teclado, con un foco visible.
  4. Cada campo de formulario necesita su <label>.
  5. Usa HTML semántico antes que atributos ARIA.
